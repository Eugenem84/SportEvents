Вечером нашлись две причины, почему переключение не проходило: (1) в сообществе URL Callback API пустой (`status: unconfigured`); (2) расхождение строки подтверждения — оказалось **артефактом сравнения**: панель показывает `8dbacc34`, и это же значение лежит в `.env` (сошлось по sha256 ожидания VK, ответа стенда по публичному домену и значения в `.env`; числа вида `6b04fced` — это хэш, а не сама строка, отсюда и путаница). Владелец сохранил URL (версия `5.199`), и VK сразу постучался `confirmation` — но события всё равно не шли: **у Callback API своя карта событий** (`groups.getCallbackSettings`, обязателен `server_id`) — сервер принят, `status: ok`, а в карте все нули. Включил `message_new` + `message_event` через `groups.setCallbackSettings`. Живая проверка: «подключить», `/старт`, нажатие «Иду» → на стенде (БД была пустая) появились беседа vk/`2000000002`, пользователь «Евгений Мёдов», игра «Волейбол» и запись на место 1. Осталось: права администратора беседы для бота (иначе `messages.pin: error 925`, анонс не закрепляется) и проверка `sign`
